# 分组竞争保存与运行契约

检查对象为 EasiNote 5.2.4.10148 的 `Main/EasiNote.Activity.dll`，SHA-256
`236058a07a567c197b3736b7659ab8f269d940b703a2b0dbc15243a0e431ec68`。
REA 静态证据 `ev_5a628d49f4d257013e6cec75855094ce96fc23b8b41ee9643a6cdf1259d39d9b`
覆盖 `GroupCompetitionHelper`、素材控件及配置项，结合定向 ILSpy 反编译读取规则。
没有执行官方窗口，不表示已经验证视觉一致。

`Key=GroupCompetition` 的配置为 `GroupCompetitionConfig`，包含 `InteractiveTheme`、
`Difficulty` 和 `Items/GroupCompetitionItem`。每项为 `Id`、`Text`、`IsCorrect`；
必须按 Id 找到同活动的真实 ActivityItem。描述文字不能用来替代缺失素材。
解析支持 XML 与保存字段名的 JSON，答案只接受显式布尔值，重复/缺失 ID、未知难度
或无法关联元素均关闭交互并保留诊断。

| 难度 | 枚举 | 下落时间 | 产生间隔 |
| --- | --- | --- | --- |
| Low | 0 | 11000ms | 2750ms |
| Medium | 1 | 9000ms | 2250ms |
| High | 2 | 7000ms | 1750ms |

支持 2 或 4 组，每组独立随机排列全部素材，在本组两列交替下落。点击正确素材 +10，
错误 -5，最低 0 分；双倍素材分别 +20/-10。连续第 3 次及后续答对，每次额外 +2；
错误清空连击。正确/错误双倍素材数量分别是各自数量的 20%/10% 四舍五入，
同类序列每 5 项标记一个，超出范围取最后一项，与官方 TagDoubleScoreSign 一致。
漏点的素材落出后不加扣分，不重置连击；重复点击、尚未下落或已落出的素材无效。

会话记录各组分数、最大连击、正确/错误次数、已经点击的素材及已用时间，按定义对象
放入 WeakMap；原始定义和 XML 不修改。暂停、切到播放选择、失焦、隐藏或卸载页面
均停止推进时间，重新进入可手动继续。结束后展示各组结果，重新开始重新随机排列。

分组区域直接位于幻灯片坐标层，随画布缩放，使用保存背景与素材，隐藏原始静止素材以免重复；
进入页面在画布内选择组数/难度并开始，无独立窗口。下落曲线与起点属于网页布局实现；时间和
分值按静态官方规则移植。没有真实竞争课件样本，当前通过构造配置、计分/时序单测
及页面生命周期交互测试验证。

## 官方界面结构对照

本轮 REA 成员证据 `ev_14014f910a99751c6310a36293acf688f20ac14e4c272811eddfdaee3e747dc9`

- 开始控件：`GroupCompetitionControlPlayControl.xaml` 使用 50% 黑色画布遮罩、794 宽的羊皮纸卡片，
  顶部题目 64 字号、活动时长 30 字号、星级难度、圆形播放按钮；入场为 450ms 分三段落下/回弹。
  题目来自 `InteractiveTheme`，现解析为 `competition.title`，XML/JSON 均支持，不存在则显示“分组竞争”。
- 头部：`GroupCompetitionControlHeaderControl.xaml` 的设计最小宽度 1920，高 212，左右各 294×120
  计分牌，中部 794×212 横幅，题目居上，`mm:ss` 计时与暂停按钮居下。不再使用通用 Radio 工具栏和白卡片。
- 区域：行为控制器两组在画布中点分隔并创建一个头部；四组在 1/4、3/4 处分隔，左右各创建一个头部。
  查看器使用两套 1920 双人设计区域并排缩放，所有区域仍在幻灯片坐标层，不修改原背景。
- 暂停：50% 遮罩、羊皮纸标题和继续/重置两个圆形按钮。重置回到设置页，再开始会重新排列素材。
- 结果：两张结果牌并排、胜负/平局、各组分数和统计，以及重置入口；四组各双人区域独立比较。
- 素材：不再限制为 160×80 小缩略图，在各组两列中按比例放大到可点选尺寸；使用保存素材自身的主题和文字。
  命中显示加减分及连击提示，双倍显示 ×2。开局倒数期间不推进活动时间、禁止计分；暂停也冻结倒数。

查看器的羊皮纸、按钮和装饰为 SVG/CSS 重绘，没有打包官方安装目录的专有位图。已实现界面结构、
