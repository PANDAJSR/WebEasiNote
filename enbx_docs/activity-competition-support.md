支持 2 或 4 组，每组独立随机排列全部素材，在本组两列交替下落。点击正确素材 +10，
错误 -5，最低 0 分；双倍素材分别 +20/-10。连续第 3 次及后续答对，每次额外 +2；
错误清空连击。正确/错误双倍素材数量分别是各自数量的 20%/10% 四舍五入，
同类序列每 5 项标记一个，超出范围取最后一项，与官方 TagDoubleScoreSign 一致。
漏点的素材落出后不加扣分，不重置连击；重复点击、尚未下落或已落出的素材无效。

会话记录各组分数、最大连击、正确/错误次数、已经点击的素材及已用时间，按定义对象
放入 WeakMap；原始定义和 XML 不修改。暂停、切到播放选择、失焦、隐藏或卸载页面
均停止推进时间，重新进入可手动继续。结束后展示各组结果，重新开始重新随机排列。

界面使用保存元素和播放器控件，没有复制官方主题两侧模板、精确轨迹、反馈声音、
开场倒计时、结束/排行榜动画或双屏逻辑。下落曲线与起点属于网页布局实现；时间和
分值按静态官方规则移植。没有真实竞争课件样本，当前通过构造配置、计分/时序单测
及页面生命周期交互测试验证。
