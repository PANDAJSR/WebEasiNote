# 07 解析流程与实现约定

## 7.1 端到端解析流程

1. 读取 ENBX（ZIP）或已解压目录
2. 解析 `Reference.xml`，建立 `resourceId -> filePath` 映射
3. 解析 `Board.xml`/`Document.xml` 生成课件元数据
4. 读取并排序 `Slides/Slide_*.xml`
5. 每页解析：背景 -> 转场 -> 动画顺序/元素动画 -> 元素列表
6. 渲染阶段按 `resourceMap` 把资源 ID 绑定到 blob URL，并按点击/键盘步进消费元素动画（当前支持 `FadeIn/FadeOut/Flicker/DiagonalWipeIn/BlindIn/TranslateIn/TranslateFadeIn`，触发器支持 `Click/Before/After` 与 `TriggerSource`，并消费 `DiagonalWipeIn/TranslateIn/TranslateFadeIn` 的 `Orientation` 与 `BlindIn` 的 `Direction`；`TranslateFadeIn` 还会消费 `Path`，并从子动画 `Line/Path` 回退取值）

## 7.2 类型与问题模型

核心类型：
- `CoursewareMetadata`
- `SlideData`
- `SlideElement`（联合类型）
- `SlideIssue`

问题分类：
- `unknown-element`
- `unknown-parameter`
- `missing-font`

`missing-font` 在 Viewer 阶段扫描文本字体可用性后追加。

## 7.3 颜色规则

`parseColor` 规则：
- `#AARRGGBB`
  - 默认返回 `#RRGGBB`
  - `preserveAlpha=true` 时返回 `rgba(...)`
- `#RRGGBB` 原样返回

## 7.4 字体与字号

- 字体来源通常是 `FontFamily/Source`
- 会做别名字体候选展开（中文字体与平台字体映射）
- 字号转换函数存在，但当前比例系数为 `1`

## 7.5 行距规则

- XML `LineSpacing` 会映射到 CSS `line-height` 倍数
- 当前换算：`1 + lineSpacing * (1/8)`
- `FixedLineSpacing` 优先级更高（按像素）

## 7.6 资源加载约定

- 资源引用统一采用 `id://<resourceId>`
- 通过 `Reference.xml` 找到 `Target`
- ZIP 模式直接按完整路径读取
- 文件夹模式按 `Target` 最后文件名在 `Resources/` 查找

注意：
- 文件夹模式若存在重名文件，理论上可能命中错误资源

## 7.7 导出回写约定

- 编辑后导出 ENBX 时，优先采用“字符串片段替换”写回元素 XML，而不是整页 DOM 重新序列化
- 这样可最大程度保留原始文本节点细节（如多行文本换行符、实体写法、CDATA 风格）并降低格式漂移风险
- 若字符串替换无法定位目标片段，再回退到 DOM replace + serialize 兜底
- 编辑态拖拽改坐标（`X/Y` 或 `Location`）同样优先做“节点片段替换”，避免把 `RichText/Text` 中的实体写法（如 `&#xD;`）改写为其他等价值形式
## 7.8 后续扩展建议

建议优先级：
1. 按 `unknown-element` 统计频率补齐元素解析器
2. 为 `ActivityItem/HanziCard/SolarSystem` 建立最小可视化占位解析
3. 在现有 `FadeIn/FadeOut/Flicker/DiagonalWipeIn/BlindIn/TranslateIn/TranslateFadeIn` + `Click/Before/After/TriggerSource` 基础上继续补齐其他 `Animations` 类型与触发器
4. 为 Group 增加旋转/变换矩阵支持
5. 完善转场键值（如 `CircleOut`、`Magic`）
