# 05 元素规范（表格/专题/几何/公式/3D）

## 5.1 Table 元素

关键字段：
- 几何：`Id/X/Y/Width/Height/Rotation`
- 单元格内边距：`CellHPadding`、`CellVPadding`
- 皮肤：`Skin`
  - `StrokeThickness`
  - `Stroke/ColorBrush`
  - `HeaderFill`
  - `RowSkins/RowSkinDetail/Fill`
- 列宽：`ColumnWidths/Item[]`
- 行：`Rows/Row[]`
  - 行高：`Row/Height`
  - 单元格：`Cells/Cell[]`

Cell 当前读取：
- `RowSpan`
- `ColumnSpan`
- `HMerged`
- `VMerged`
- `Text`（复用 Text 解析器）

## 5.2 Topic（思维导图）元素

关键字段：
- 根：`Title/Type/BranchType/ContentWidth/ContentHeight`
- 样式：`NodeStyle`、`NodeStyleInfo`、`Skin`、`SkinInfo`
- 子节点：`Children/Node`

子节点字段：
- `NodeId`
- `Location`（x,y）
- `Title`
- `ContentWidth`/`ContentHeight`
- `NodeStyle`/`NodeStyleInfo`
- `Children`（递归）

当前实现输出为树结构 `TopicNode[]`。

## 5.3 GeometryElement（几何画板）

关键字段：
- `Geometries/Geometry[]`
  - `Type`
  - `Points/Point[]`
  - `Stroke/ColorBrush`
  - `StrokeThickness`
  - `LineType`
  - `SegmentType`
  - `AngleOfEllipse`
- `Angles/Angle[]`
- `Marks/Mark[]`

## 5.4 MathFormula（数学公式）

关键字段：
- `Foreground/ColorBrush`
- `MathML`

解析规则：
- 移除 XML 声明头
- 解析并定位 `<math>` 根
- 把私有 `<matom>` 节点平铺成文本
- 输出：
  - 标准化 `mathML`
  - `fallbackText`（纯文本兜底）

## 5.5 RuledPaper（四线三格）

此元素在当前实现中复用 Text 元素输出，并额外携带：
- `lineColor`（`LineColor/ColorBrush`）
- `backgroundColor`（`Background/ColorBrush`）
- `opacity`

文本来源：`RuledPaper/RichText`

## 5.6 3D 元素（Cylinder/Cone/Cube）

通用字段：
- 几何：`Id/X/Y/Width/Height/Rotation`
- 边：`EdgeThickness`、`EdgeBrush/ColorBrush`
- 面：`Surfaces/Surface/Fill/ColorBrush`

当前颜色映射：
- Cylinder：top/side/bottom
- Cone：side/base
- Cube：top/front/right

说明：
- `Transform3D`、`Edges`、展开状态等高级字段当前不参与渲染计算
