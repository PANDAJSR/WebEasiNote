# 05 元素规范（表格/专题/几何/公式/3D）

## 5.1 Table 元素

关键字段：
- 几何：`Id/X/Y/Width/Height/Rotation`
- 单元格内边距：`CellHPadding`、`CellVPadding`
- 皮肤：`Skin`
  - `StrokeThickness`
  - `Stroke/ColorBrush`
  - `HeaderFill`
  - `RowSkins/RowSkinDetail/Fill`
- 列宽：`ColumnWidths/Item[]`
- 行：`Rows/Row[]`
  - 行高：`Row/Height`
  - 单元格：`Cells/Cell[]`

Cell 当前读取：
- `RowSpan`
- `ColumnSpan`
- `HMerged`
- `VMerged`
- `Background`（单元格独立背景，优先于行列皮肤）
- `Text`（复用 Text 解析器）
- `TableCellTextMarginExtension/TextMargin`（`左,上,右,下`，逐格覆盖内边距）

内边距语义（官方 `TableCell` 构造函数，见 `Cvte.Paint.Shell.dll`）：
- `CellHPadding/CellVPadding` 取 `Math.Max(保存值, 24)`，默认 24；
- 单元格四边留白 = `(CellHPadding/2, CellVPadding/2, CellHPadding/2, CellVPadding/2)`；
- 存在 `TableCellTextMarginExtension` 时直接使用其 `TextMargin` 覆盖四边留白。
- 实测语料：`CellHPadding=24/25.6`、`CellVPadding=24`，`TextMargin` 为 `12.8,12,12.8,12` 或 `10.667×4`。

## 5.2 Topic（思维导图）元素

关键字段：
- 根：`Title/Type/BranchType/ContentWidth/ContentHeight`
- 样式：`NodeStyle`、`NodeStyleInfo`、`Skin`、`SkinInfo`
- 子节点：`Children/Node`

子节点字段：
- `NodeId`
- `Location`（x,y）
- `Title`
- `ContentWidth`/`ContentHeight`
- `NodeStyle`/`NodeStyleInfo`
- `Children`（递归）

当前实现输出为树结构 `TopicNode[]`。

渲染兼容性：节点与连线路径使用页面坐标，Topic 画布应显式使用页面宽高（乘渲染缩放比例）。元素定位包装层没有尺寸，使用百分比宽高会使 SVG 视口变为 `0×0`，出现节点可见但连线消失的情况。

## 5.4 MathFormula / ChemicalFormula（数学、化学公式）

关键字段：
- `Foreground/ColorBrush`
- `MathML`

解析规则：
- 移除 XML 声明头
- 解析并定位 `<math>` 根
- 把私有 `<matom>` 节点平铺成文本
- 公式文本可能使用旧 Symbol 字体私用区编码（如 `U+F022=∀`、`U+F024=∃`、`U+F0CE=∈`、`U+F0B4=×`、`U+F0D7=⋅`）；已知编码转换为 Unicode，未知私用区字符保持原样。官方 `Cvte.Windows.MathEditor.dll` 的 `OperatorSymbols` 静态初始化也使用这些编码。
- Chromium 不支持旧式 `mfenced`，需转换为 `mrow` 与可伸缩的 `mo`，保留嵌套括号、绝对值和分隔符。实测分段函数 `open="{"` 且无 `close` 表示只有左大括号；显式空 `close` 同样不生成右括号。
- 平方根可保存为第二个子节点为空的 `mroot`，转换为 `msqrt`；有非空指数的 `mroot` 保留。
- 均值横线可能保存为 `mover` 的第二个子节点内的组合字符 `U+0305`，转换为可伸缩的横线重音，避免浏览器把横线单独显示在上标位置。
- `ChemicalFormula` 与 `MathFormula` 使用同一套 MathML 解析与渲染，输出 `mathFormula`；真实复杂元素样本包含加热条件、上下标及气体箭头。
- 渲染使用数学字体，测量实际排版宽高后等比适配元素边界，支持放大或缩小；不通过裁剪隐藏超宽公式。字体度量由浏览器决定，与官方仍可能存在间距差异。

符号编码证据：REA 静态检查官方 5.2.4.10148 的 `Cvte.Windows.MathEditor.dll`，SHA-256 `f034f320b6bbe3c07be2aa724fffbf304436d1b4e005b8154dd173ebf6864218`，MVID `99a59efd-6a87-4574-b0b7-00833276c999`，Evidence `ev_e3ad2cac001449950f3c39cbfe287dde4eef07759746a23b82dbdf2deb1e4cc4`。`OperatorSymbols..cctor` 的 `ldstr → stsfld` 对应关系确认 AnySymbol、ExistSymbol、BelongToCommand、TimesCommand、DotMultiplyCommand 等编码；这是文件静态证据，未执行官方程序。根式和括号转换规则来自本地缓存课件的实际 XML 与 Chromium 渲染验证。
- 输出：
  - 标准化 `mathML`
  - `fallbackText`（纯文本兜底）

## 5.5 RuledPaper（四线三格）

此元素在当前实现中复用 Text 元素输出，并额外携带：
- `lineColor`（`LineColor/ColorBrush`）
- `backgroundColor`（`Background/ColorBrush`）
- `opacity`

文本来源：优先 `RuledPaper/RichText`；没有 `RichText` 时兼容 `Words`，按 CRLF/CR/LF 分行。没有文本仍保留空练习纸和格线。

`Words` 模式使用官方 96 自然字号；所有分支固定使用官方 `SeewoEnglishHandwriting`，包括读取 RichText 后。字号、颜色及粗斜体等 RichText 样式仍保留。字体随前端内嵌加载，格线按官方 XAML 的 140 周期、24 顶边距及 1/1/3/1 线厚渲染；详细证据、加载方式和布局限制见 [四线三格字体与布局](09-四线三格字体与布局.md)。

## 5.6 3D 元素（Cylinder/Cone/Cube）

通用字段：

- 边：`EdgeThickness`、`EdgeBrush/ColorBrush`

当前颜色映射：
- Cylinder：top/side/bottom
- Cone：side/base
- Cube：top/front/right

说明：
- `Transform3D`、`Edges`、展开状态等高级字段当前不参与渲染计算
