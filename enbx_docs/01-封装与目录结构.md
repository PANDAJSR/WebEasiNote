# 01 封装与目录结构

## 1.1 ENBX 本体

ENBX 在本项目中被视为 ZIP 容器。

核心入口文件：
- `Board.xml`
- `Document.xml`
- `Reference.xml`
- `Slides/Slide_*.xml`
- `Resources/*`

解析入口代码：
- `src/parser.ts` 中 `parseENBXFile`
- 对已解压目录同样支持（`parseExtractedFolder`）

## 1.2 目录结构（已观测）

典型结构：

```text
课件根目录/
  Board.xml
  Document.xml
  Reference.xml
  SaveInfoMetadataFile.xml
  Slides/
    Slide_0.xml
    Slide_1.xml
    ...
  Resources/
    *.png/*.jpg/*.mp4/*.mp3/*.svg/无后缀资源
  thumbnail.png (可选)
```

说明：
- `SaveInfoMetadataFile.xml` 在当前项目中不参与解析，仅用于能力线索
- `thumbnail.png` 不参与解析渲染
- `Resources` 下存在“有扩展名/无扩展名”两类资源文件

## 1.3 幻灯片组织方式

当前实现按 `Slides/Slide_数字.xml` 文件名排序加载。

这意味着：
- 实际渲染顺序以文件编号为主
- `Board.xml` 中的 `Slides/Item` 同时提供了逻辑页 ID 列表

## 1.4 文件缺失容错

当前实现：
- `Board.xml` 缺失：直接判定无效课件
- `Document.xml` 缺失：允许，元数据使用默认值
- `Resources` 缺失：允许，资源计数为 0
- `Slides` 缺失：允许，最终无页面
