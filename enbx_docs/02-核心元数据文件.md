# 02 核心元数据文件

## 2.1 Board.xml

职责：
- 课件级画布尺寸（`SlideWidth`/`SlideHeight`）
- 页面 ID 列表（`Slides/Item`）
- 主题（`ThemeForBoard`）

当前实现主要读取：
- `Slides/Item` 用于生成 `slideIds`
- 页数 `slideCount`

示例（简化）：

```xml
<Board>
  <SlideWidth>1280</SlideWidth>
  <SlideHeight>720</SlideHeight>
  <Slides>
    <Item>351ae513-f65e-44bf-a091-7440c973a8d6</Item>
  </Slides>
</Board>
```

## 2.2 Document.xml

职责：文档级元信息。

当前映射：
- `Name` -> 课件名
- `Creator` -> 创建者
- `AppVersion` -> 应用版本
- `DocumentVersion` -> 文档版本
- `ModifiedDateTime` -> 修改时间

`formatDateTime` 支持 `MM/DD/YYYY HH:mm:ss` 这类字符串格式化显示。

## 2.3 Reference.xml

职责：资源 ID 与资源路径映射。

结构：
- `Relationships/Relationship`
- 每项通常有 `Id`、`Hash`、`Target`

当前实现只使用：
- `Id`
- `Target`（并把反斜杠转为正斜杠）

示例（简化）：

```xml
<Relationship>
  <Id>66c593b78d9bfebbe681ae28718033e2</Id>
  <Target>Resources\66c593b78d9bfebbe681ae28718033e2.mp4</Target>
</Relationship>
```

## 2.4 SaveInfoMetadataFile.xml

在样例中用于声明类型能力（如 `Text/Shape/Table/Topic/...`），
当前项目不参与业务解析，但可作为后续扩展“类型发现器”的来源。
