## 6.3 已支持元素中的“部分未消费字段”

常见未消费字段：
- 动画：`Animations/*`（已消费 `FadeIn/FadeOut/Flicker` + `Click/Before/After`，其余类型/触发器未消费）
- 超链接：`Hyperlink`
- 锁定/克隆：`IsLocked`、`CanClone`
- 遮罩相关：`HasMask`
- 某些样式扩展：`DashStyle`、`TextFill` 等

这些字段一般不会导致解析失败，但目前不参与渲染行为。

## 6.4 Group 限制

- 支持位置偏移
- 不支持 Group 自身旋转矩阵

## 6.5 转场限制

样例中出现的 `TransitionKey` 包括：
- `Fade`
- `SlideToLeft/Right/Top/Bottom`
- `CircleIn`
- `LineReveal`
- `CircleOut`
- `Magic`
- `None`

当前 UI 动画实现主要覆盖：
- `Fade`
- 四向 Slide
- `CircleIn`
- `LineReveal`

其余键值默认按“无特效/降级”处理。
