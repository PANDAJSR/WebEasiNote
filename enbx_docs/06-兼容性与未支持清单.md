## 6.3 已支持元素中的“部分未消费字段”

- `ActivityItem` 已接入静态展示，经典 `Classify` 支持按元素 ID 分类、单指针拖动、判题、进度和重置，并协调播放选择。其他活动仅静态展示；详见 [09 课堂活动](./09-元素规范-课堂活动.md)。当前以官方静态契约和人工 XML fixture 验证，尚无真实活动课件及宿主触摸实测。

- `Audio` 已支持播放、裁剪、打点及循环，见 [04 多媒体](./04-元素规范-文本图形多媒体.md)。
- `HanziCard/PinyinCard/EnglishWordCard` 已支持显示与部分授课交互；`ClassicalWorkElement/VocabularyPage/QuestionCard/DictationCard/Chart/MathFunction/SolarSystem` 及资源卡已接入，详见 [08 学科卡片及复杂元素](./08-元素规范-学科卡片.md)。真实 `复杂元素.enbx` 的 12 页均可识别，已对照用户提供的官方截图校准主要布局；这不代表所有官方行为均已复刻。
- 汉字/拼音笔顺、手写识别、连续朗读、自动听写、图表编辑/3D、函数参数编辑/隐式曲线/交点，以及地球的太阳系、百科、结构剖面和天体运动仍未实现。网页、实验与 AI 资源使用保存封面及 HTTP(S) 授课 URL，在线内容依赖官方服务。
- `RuledPaper` 支持 `RichText`、旧版 `Words` 及空白练习纸；字号和格线仍需官方校准。

常见未消费字段：
- 已补齐的真实动画类型：`RandomizedLinesInEffect`（“线条”入场）已参与点击队列、初始隐藏及回退，支持水平/垂直随机条纹揭示。补充预设枚举不代表已覆盖实际课件中所有 `Animation/Type` 名称。
- 动画：已支持现有明确类型，以及官方 Office 转换器枚举中的入场/退出与强调预设映射。补充预设使用通用 CSS 效果近似，不能视为与官方播放器逐帧一致；`TranslateIn`/`TranslateFadeIn` 支持直线路径位移，动画中心、重复次数、频率和加减速参数已消费。运行时未在本机官方播放器中实测，未来遇到未知 `Type` 仍需补映射。
- 超链接：`Hyperlink`
- 锁定/克隆：`IsLocked`、`CanClone` 已解析为直接子字段，默认 false，参与宿主放映选择。Group 标记向展开后的子元素传播。原地保留克隆源，拖出独立 ID、`CanClone=false` 的副本；取消不留下副本。触摸暂采用相同策略，未复现官方触摸路径的 ID/动画归属交换。
- 遮罩相关：`HasMask`
- 某些样式扩展：`TextFill` 等（`DashStyle`/`PenSetting` 已按官方语义消费，见 4.2）
- 表格单元格文本边距 `TableCellTextMarginExtension/TextMargin` 已消费；`CellHPadding/CellVPadding`
  已按官方 `Math.Max(值, 24)` 收敛并取一半作为每侧内边距
- Flash：`HasMask`（弹窗播放不受蒙版影响）、`SaveInfoMetadata`（仅元数据）；
  SWF 帧级进度/跳帧依赖 Ruffle 未提供的 API

这些字段一般不会导致解析失败，但目前不参与渲染行为。

## 6.4 Group 限制

- 支持位置偏移
- 支持 Group 自身旋转并展开为子元素几何；放映选择以最外层组合为单位，使用外接矩形和等比缩放。组合解组和专用组坐标选框未实现。
- 放映选择支持空白区域套索多选（自动闭合，覆盖至少 50% 即可），以及 Shift/Ctrl/Meta 追加选择。覆盖率按元素旋转后的局部矩形面积、64 条扫描线近似计算，凹形/自交套索按奇偶填充；组合按成员面积加权达到 50% 即整体选中，不再要求完全包围所有成员，但全部成员必须可选。锁定/隐藏/动画运行中的成员会阻止整组选择。多选共用外接选框，可整体移动、等比缩放和旋转。这是本项目交互策略，非官方阈值结论；不涉及宿主墨迹选择。
- 放映选择菜单按官方 `5.2.4.10148` 静态资源还原：64×56 控件、24×24 原图标、微软雅黑 12、原九宫格阴影、双层 80% 背景和状态色。资源说明见 `src/components/selection/assets/README.md`；没有官方运行截图逐像素验证，菜单绝对间距/跨 DPI 字体渲染和展开的颜色/裁剪面板仍有差异。
- 放映选择的所有缩放手柄（包括边手柄）均强制等比例，不依赖 Shift；文本整体缩放字号、行距、段落间距、内边距及边框/效果，保持原文字排版，而非仅改变文本框。内部 `playbackContentScale` 只用于会话显示，并非新增 XML 字段；单选、组合、多选和连续缩放共用此策略。

## 6.5 转场限制

样例中出现的 `TransitionKey` 包括：
- `Fade`
- `SlideToLeft/Right/Top/Bottom`
- `CircleIn`
- `LineReveal`
- `CircleOut`
- `Magic`
- `None`

当前 UI 动画实现主要覆盖：
- `Fade`
- 四向 Slide
- `CircleIn`
- `LineReveal`

其余键值默认按“无特效/降级”处理。
