## 6.3 已支持元素中的“部分未消费字段”

常见未消费字段：
- 已补齐的真实动画类型：`RandomizedLinesInEffect`（“线条”入场）已参与点击队列、初始隐藏及回退，支持水平/垂直随机条纹揭示。补充预设枚举不代表已覆盖实际课件中所有 `Animation/Type` 名称。
- 动画：已支持现有明确类型，以及官方 Office 转换器枚举中的入场/退出与强调预设映射。补充预设使用通用 CSS 效果近似，不能视为与官方播放器逐帧一致；`TranslateIn`/`TranslateFadeIn` 支持直线路径位移，动画中心、重复次数、频率和加减速参数已消费。运行时未在本机官方播放器中实测，未来遇到未知 `Type` 仍需补映射。
- 超链接：`Hyperlink`
- 锁定/克隆：`IsLocked`、`CanClone`
- 遮罩相关：`HasMask`
- 某些样式扩展：`TextFill` 等（`DashStyle`/`PenSetting` 已按官方语义消费，见 4.2）
- 表格单元格文本边距 `TableCellTextMarginExtension/TextMargin` 已消费；`CellHPadding/CellVPadding`
  已按官方 `Math.Max(值, 24)` 收敛并取一半作为每侧内边距
- Flash：`HasMask`（弹窗播放不受蒙版影响）、`SaveInfoMetadata`（仅元数据）；
  SWF 帧级进度/跳帧依赖 Ruffle 未提供的 API

这些字段一般不会导致解析失败，但目前不参与渲染行为。

## 6.4 Group 限制

- 支持位置偏移
- 不支持 Group 自身旋转矩阵

## 6.5 转场限制

样例中出现的 `TransitionKey` 包括：
- `Fade`
- `SlideToLeft/Right/Top/Bottom`
- `CircleIn`
- `LineReveal`
- `CircleOut`
- `Magic`
- `None`

当前 UI 动画实现主要覆盖：
- `Fade`
- 四向 Slide
- `CircleIn`
- `LineReveal`

其余键值默认按“无特效/降级”处理。
