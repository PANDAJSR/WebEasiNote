从已核对 Resources DLL 的文件偏移 380615 提取 26496 字节的独立 sfnt 字体，名称表的字体族为 `SeewoEnglishHandwriting`、样式为 Regular。

- 字体 SHA-256：`433589be26f881d4d745892590bad682f4c2598e092079efc2597d5fce6d5719`。
- unitsPerEm：2048；hhea ascent/descent/lineGap：1716/-418/222。
- OS/2 fsType：0。此字段是技术嵌入标记，不能替代字体版权或再分发许可。
- `scripts/extract-ruled-paper-font.py` 检查 DLL 与字体的双重哈希后生成 `src/text/ruled-paper-font.ts`。
- 使用私有 CSS 字体族 `WebEasiNote Ruled Paper` 和内嵌 `data:font/ttf`，不依赖客户端安装字体、网络地址或 WPF pack URI。普通文字的字体回退逻辑不受影响。
- 生成文件中的字体来源是官方安装包，项目 AGPL 不改变此资源原有权利归属。

## 布局参数

以下数值来自官方 XAML，使用 Viewbox 内的自然坐标：

| 项目 | 数值 |
| --- | --- |
| Root Grid 最小宽 | 148 |
| 格线区域边距 | 左右 12，顶部 24，底部 0 |
| 重复格线周期 | 140 |
| OuterBorder 边距 | 顶 20，底 23；上下各 1 |
| InnerBorder 边距 | 顶 52，底 54；上 1，下 3 |
| 四条色带位置 | 格线区内 y=20、52、83、116；厚度 1、1、3、1 |
| TextEditor 边距 | 左右 36，底部 12 |
| TextEditor 水平位置 | 整个编辑器居中；段落保留左对齐 |

解编译中的单段自然高度为 164.3；扣除顶部 24 得到每段 140.3。当前实现用 `140.3 × 段数 + 24` 计算自然高度，并以保存的 Height 等比换算 Viewbox 坐标；格线图案仍每 140 重复，不能把段落间的空隙抹掉或将多组四线合并成连续三等分。

`Opacity` 只作用于 ShadowContainer 的纸面背景；格线和文字不随它一起透明。背景、格线均保留颜色自身的 alpha。
