# 08 元素规范（学科卡片及复杂元素）

本页区分保存契约与当前实现。字段依据官方 5.2.4.10148 静态检查、真实 `复杂元素.enbx`（12 页）的 XML 与内嵌图片，以及用户提供的官方播放器截图。已校准主要尺寸和布局，并在 Chromium 中逐页检查资源及实际渲染；未在官方运行时执行控件，不保证字体、动画和全部交互一致。`tests/fixtures/subject-cards.xml` 及复杂元素测试中的 XML 是按契约构造的回归夹具，不是真实课件取证。

## 8.1 HanziCard

- 输出类型：`hanziCard`，通用位置、尺寸、旋转及原始 XML 保留，参与组偏移及动画包装。
- 新版：`HanziList/HanziInfo[]`，条目字段 `Hanzi/Pinyin/PinyinList/Radical/StrokeCount/StrokeCode`。
- 旧版：没有列表时使用顶层 `Character/Pinyin`。
- `PronounceList/Pronounce[]`：`Name` 是读音资源名，`Source` 是资源标识。
- 当前显示汉字、保存的注音、部首、笔画数，支持多音字切换及已保存音频播放；不会自行查询或补造词条数据。
- `StrokeCode` 保留为顺序编码，不能当成路径。官方调用 `ChineseStrokesModuleService`，结合 `ChineseTtfDataProvider` 与 `ChineseStrokeDataProviderBySql` 生成笔画几何。
- 已实现汉字笔顺：黑色整字底层、红色逐笔遮罩、单步/连写、点击笔画蓝色强调；最后一笔结束后空闲 1000ms 恢复黑字。单步运行中忽略重复点击，切换模式重新开始，离页、进入静态模式、页面隐藏时取消播放。
- 轮廓采用官方专用 TTF 的 GDI+ 原始子路径点（含贝塞尔控制点）生成闭合折线；`StrokeOrder[i]` 指定原始子路径 i 的书写序号，并引用 `Geometry.split('&')[order]`。不从 `StrokeCode` 或普通字体推导几何。
- 本地字库来自 ChineseStrokes 依赖版本 2363，随播放器离线发布，按 Unicode 高位分成 81 片并按需加载。数据库共 5525 字，其中 4941 字通过专用字体 cmap 及子路径数量校验；584 字缺少字体映射，回退静态整字并禁用播放。12 条记录含未引用的额外轨迹，仅使用映射引用部分。
- 内部坐标 300×300（GDI+ emSize=300，X 偏移 -45），缩放为 120×120 并居中放入 156×156 田字格；遮罩直径 40，持续时间 `max(160, length * 8)` ms，红色 `#DC143C`、蓝色 `#2E7DE6`。SVG 连续路径遮罩复现官方累积圆形揭示方式，未做官方运行时逐帧像素对比，也未全字视觉检查。
- 资源及哈希见 `public/hanzi-strokes/manifest.json`；转换工具为 `scripts/convert-official-hanzi.py` 与 `scripts/export-hanzi-font.ps1`，仅离线转换需要 Windows GDI+ 和源字体/数据库，运行时不依赖希沃安装。
- 连续朗读、手写识别仍未实现；`IsInHandWriteMode` 保留到模型，并继续报告为未消费参数。

## 8.2 PinyinCard

- 输出类型：`pinyinCard`。
- 新版：`PinyinInfoList/PinyinInfo[]`；旧版使用顶层同名字段。
- 条目字段：`Pinyin/TonePinyin/IsTonePinyinsVisible/PronounceList`。
- 新版条目缺少音频列表时兼容顶层 `PronounceList`。
- 单音节支持四声候选展开和“标调”；多音节整句采用逐音节声调下拉，忽略每个条目的候选展开状态。声调候选按 a/e/ou/末元音顺序生成，支持 ü；读音只使用课件保存的资源。
- `LineColor/ColorBrush` 与 `Opacity` 参与渲染；卡片背景采用官方控件的白色面板。四线与按钮按 170 高的设计尺寸缩放，字体度量仍受浏览器字体影响。
- `Brushes` 逐笔颜色和 `IsDisplayMode` 未消费，仍报告参数问题；书写动画、连续播放未实现。
- 官方 `GetPinyinCharacterGeometry` 使用字体生成字形轮廓（`FormattedText.BuildGeometry`），完整动画实现依赖匹配的字体与动画规则。

## 8.3 EnglishWordCard

- 输出类型：`englishWordCard`。
- `Word/Soundmark/Remark` 为纯文本，浏览器不解释为 HTML。
- `Semantics/SemanticInfo[]`：`Semantic/PartOfSpeech`。
- `Sentences/SentenceInfo[]`：`Sentence/Translation`。
- `Phrases/PhrasesInfo[]`：`Phrase/Translation`。
- `Synonym/SynonymsInfo[]`：`Word/Soundmark/PronounceSource/Semantics`。
- `CurrentContentType` 支持官方枚举名和对应数字：`Semantic=0/Phrase=1/Sentence=2/Synonym=3`，未知值回退 `Semantic`。
- `IsCollapsed` 决定初始展开状态；`ScaleRatio` 缩放内部布局，保留元素保存边界。
- 当前实现四栏目切换、展开/收起、内容滚动、词条和近义词发音。
- `PronounceFileName/ResourcePattern` 作为保存上下文识别，不推导未验证的下载地址；浏览器不执行 `ResourcePattern` 的资源生成行为。
- 未实现词条查询、编辑及生成详情页；授课中的栏目、声调和读音切换仅为组件状态，不写回课件；离页卸载后再次进入恢复文件保存的初始状态。

## 8.4 资源与交互

- 音频通过 `id://` 在 Reference 映射中解析，也接受课件逻辑路径和已保存的 HTTP(S) 地址；不拼接未知云端接口，不读取任意 `file://` 路径。
- 本地 ZIP/文件夹仅补读卡片显式引用的路径；HTTP 文件源沿用清单资源映射，媒体 `preload=none`。
- 读音匹配兼容带调元音和数字调资源名，例如 `xíng ↔ xing2`、`lǜ ↔ lv4`，不自动选用其他读音代替缺失资源。
- 缺失音频禁用按钮，播放失败显示状态；离开当前页、进入编辑模式、隐藏或卸载时停止播放，并拦截过期异步播放结果。
- 同一卡片内开始播放时暂停其他音频，避免近义词与主词条重叠。
- 缩略图保留卡片静态外观；仅当前页授课时挂载发音媒体，预览、编辑及非活动页不挂载音频。
- 授课内部操作通过 `data-subject-control` 避开元素点击动画，`data-prevent-swipe` 避开滑动翻页；编辑模式保留父层选择、拖动。

## 8.5 ClassicalWorkElement（古诗词）

- 输出 `classicalWork`，读取 `Title/Author/WorksIntroduction/AuthorIntroduction/ThemeBrush/ClassicalWorksState`。
- `IsTitleIntroductionShow/IsAnthorIntroductionShow`（保存格式本身拼作 Anthor）控制简介初始显隐；点击题目或作者切换简介。
- `Editors` 保存正文富文本；`TranslationOriginalEditors`、`TranslationExpandEditors` 保存原文和译文。每个编辑器读取 `EditorWidth/RichText/TextLines`，保留字号、字体、颜色与分段。
- 缺少编辑器时回退 `Content/Translation` 纯文本。支持左侧原文／翻译切换，译文模式按原文与译文两列显示。
- `TranslationPackUpEditors/KeyPointBrush/Wiki/AuthorWiki/Audio` 等上下文保留在原始 XML；未实现重点批注、百科及诗词内置连续朗读。样本中独立 `Audio` 元素由音频渲染器处理。

## 8.6 VocabularyPage（词汇详解页）

- 与浮动词典卡片 `EnglishWordCard` 不同，`VocabularyPage` 使用整页布局和左下纵排栏目按钮。
- 读取 `Word/Pronounce/PronounceSource/EnglishWordContentType`；`Pronounce` 是显示音标。
- `Semantics/Phrases` 直接保存编辑器富文本；`Sentences` 包含 `Sentence/Translation`；`Synonym` 包含 `Word/Soundmark/PronounceUri/Semantics`。
- 支持释义、词组、例句、近义词切换及已保存发音；不补查网络词典。

## 8.7 QuestionCard（题卡）

- 输出 `questionCard`，读取 `QuestionTypeName/QuestionSource/OptionSource/AnswerSource/AnalysisSource/IsCollapsed/ScaleRatio/ImageScale`。
- 各 Source 是独立图片，不是可解析的题目文本。`IsCollapsed=True` 时显示题干和选项，展开后增加答案与解析；浏览器不判断选择结果。
- `ScaleRatio` 缩放整个题卡，`ImageScale` 独立缩放图片原始像素，非正值回退 1。不能仅将图片撑满卡片宽度，否则会增大题干并裁切选项。
- 真实样本图片宽度 2668，`ImageScale=0.25`，显示宽度为 667；外框保存宽度为 743 或 769。选项采用左竖线及缩进，与官方截图一致。
- 展开会增加卡片高度；当前不修改课件层级及保存数据，展开后的遮挡与官方置顶操作可能不同。

## 8.8 DictationCard（听写）

- 读取 `Title/Count/UnitsInfos`，每个单元的 `WordsInfos` 保存 `Word/PhoneticSymbol/WordInterpretation/MaleAudioUri/FemaleAudioUri`。
- 音频 URI 为空时可使用保存的 `MaleDownloadAudioUrl/FemaleDownloadAudioUrl`，不生成下载地址。
- 显示标题、单词数量和“查看单词”，弹窗可查看词汇及逐词播放音频；未实现设置、自动顺序听写、间隔和评分。

## 8.9 Chart（图表）

- 输出 `chart`，真实样本的 `ChartType` 为 `Histogram/Line/Pie`（柱图、折线、饼图）；`Is3DChart` 保留，暂按二维绘制。
- `Data/ChartData[]` 是类别，`Title` 为类别名；各 `Values/ChartText[]` 的下标是系列，读取文本、`Foreground/ColorBrush`、字号。`DataType` 表示编辑数据表方向，不据此转置渲染数据。
- `Materials/Material/MaterialBrush` 是系列／扇区配色，`CoordinateSkin/CoordinateBrush` 为网格颜色，`DataTagVisible` 控制数据标签。
- `Legend` 包含 `Location/Contents/IsVisible/Width`；图例使用自己的字号和前景色。饼图类别名称来自 `Data/Title`，样式取图例保存值，不能直接继承扇区内的白色 24 号字。
- 图例在保存的 Location、Width 区域内居中排布；饼图百分比位于半径约 0.75 处。坐标刻度和系列间距使用浏览器计算，未覆盖全部官方皮肤和编辑交互。

## 8.10 MathFunction（函数图像）

- 输出 `mathFunction`，`FuncViewerSaveInfo` 下的 `FuncMeshSaveInfo` 保存 `BasicSize/GraduationTagStep/GraduationTagValueStep/GraduationTagScale/ShowTypes`；`VisualBounds` 位于 Viewer 层。
- 官方内部坐标板为 2000×2000，原点为 `(1000,1000)`。可视原点等于内部原点减 `VisualBounds.X/Y`，再缩放到左侧正方形绘图区；不能把可视原点固定在绘图区中心。
- 数学坐标单位的像素数：`BasicSize × GraduationTagStep / (GraduationTagValueStep × GraduationTagScale)`，再应用绘图区缩放。当前右侧显示表达式列表。
- `FunctionCollection/NormalFuncSaveInfo` 包含 `ID/FunctionString/FuncBrush`。样本表达式为 `(x)^(2)` 和 `(x)^(-1)`；`MathExpressionCollection` 保留原始上下文，未用于表达式编辑。
- 受限解释器支持 x、pi、e、四则运算、幂、隐式乘法和常见单参数函数；限制长度和嵌套，不执行动态 JavaScript。不支持的表达式保留列表并提示，不绘制曲线。
- 支持拖动、缩放、网格开关、复位；非有限值及大幅跳变断开曲线。未实现参数滑块、交点、导数、隐式／参数曲线和官方全部函数语法。

## 8.11 SolarSystem（地球仪）

- 输出 `solarSystem`，当前实现 `PlanetSystemType=Earth`、`PlanetState=Overall` 的地球整体视图。其他星体系统显示暂不支持提示。
- 读取 `EarthTextureKey/EarthTextureType/PlanetView/CameraPosition/CameraLookDirection/CameraUpDirection/Texture2DMatrix`。
- `Textures` 的每项有 `Key/Brush/ImageBrush/Source`；`Maps` 的每项有 `Key/Uri`。资源从课件读取，不随组件下载额外地图。
- 三维视图优先通过 WebGL 使用内嵌真实纹理做球面透视投影，无 WebGL 时回退 Canvas；纹理使用线性过滤，支持高像素密度屏幕。完整元素矩形是相机视口，水平视角 45°；保存的相机观察目标偏移、上方向及视口宽高比参与投影，不能把球面固定绘制在居中正方形内。
- 拖动会围绕保存相机的上方向及右方向旋转，保留原有倾斜与观察方向；支持按钮／滚轮缩放、双击／按钮复位、地图选择，编辑模式禁止内部交互。地图选项合并 Maps 与可识别的 Textures，球面与平面资源分别读取。
- 二维视图按完整视口等比显示平面地图，应用保存的 `Texture2DMatrix`（WPF 六项顺序与 CSS matrix 一致：M11,M12,M21,M22,OffsetX,OffsetY）；支持拖动平移与缩放，复位恢复课件保存状态。
- 月球和轨道是静态外观近似，不是天体运动模拟；背景使用课件页面背景，与官方星空渲染可能不同。
- `FocusedSatelliteKey/FocusedPlanetRadius2D/PlanetKnowledgePanel/Wikis` 保留于原始 XML。未实现百科、探索太阳系、剖面、昼夜光照及精确卫星位置，不据此绘制无功能按钮。
- 星球实现与证据的详细边界见 [solar-system-rendering.md](solar-system-rendering.md)。

## 8.12 网页、实验、AI 与物理图资源卡

- `WebPresentationCard2`、`TeachingDrawingBoardCard`、`NoBookExperiment`、`AIToolCard`、`PhysicalGraph` 统一输出 `resourceCard`，保留具体 kind。
- 封面依次读取 `Thumbnail/ThumbUri/Thumb/ImageUri`；网页卡读取 `LayoutSize/IsTitleVisible/IsThumbnailVisible/ButtonContent/DisplayUrl`，其他卡保留标题和保存的授课地址。
- AI 卡另读取 `ElementName/Text/IconUri/ButtonImageUri`；`PhysicalGraph` 使用透明背景显示保存的电路图封面，不运行物理仿真。
- 仅 HTTP(S) 的 `DisplayUrl` 可打开；使用新窗口和 `noopener,noreferrer`。离线可显示内嵌封面，在线内容、鉴权、音视频及实验执行依赖原服务，不内嵌运行原生插件或执行编辑地址。
