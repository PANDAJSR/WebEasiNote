## 证据与范围

依据本机官方 `5.2.4.10148` 的 `EasiNote.Api.dll`、`EasiNote.Business.dll` 和
`EasiNote.Activity.dll` 静态检查实现。活动 DLL SHA256：
`236058a07a567c197b3736b7659ab8f269d940b703a2b0dbc15243a0e431ec68`。
检查的类型包括 `ActivityElementSaveInfo`、`ActivitySaveInfo`、

`SuperClassifyActivityBehaviorController`、`ActivityContainerElement` 和 `ClassifyActivityElementRules`。

`tests/fixtures/activity-classify.xml` 是根据保存契约人工构造的测试数据，

## 保存定义和页面成员

页面扩展 `Extensions/Activity`（同时兼容页面直接子节点 `Activity`）保存：

| 字段 | 含义 |
| --- | --- |
| `Id` | 活动资源/主题标识 |
| `Key` | 玩法，如 `Classify`、`SuperClassify`、`GapFilling`、`TextMatch` |
| `IsPlayAudio` | 官方活动声音开关；当前不播放官方反馈音效 |
| `Config` | 玩法配置；分类配置契约为 `ClassifyConfig` |
| `ActivitySetting`、`ComponentId`、`ComponentName` | 保留原始 XML，目前不解释模板或组件行为 |

`Elements/ActivityItem` 是页面元素。`ResourceType` 表示角色，**不是玩法**：
`Background=0`、`Container=1`、`Material=2`，解析器支持名称和数字。
`ActivityId` 关联主题，`ResourceId` 关联模板资源；不能用 `ResourceId` 判定答案。

支持通用位置、尺寸、旋转，以及 `Background`、`Stroke`、`StrokeThickness`、
`RoundRadius`、`TextEditorWidth`、`Contents`。画刷复用已有 Brush 解析；
`Contents` 使用现有元素解析器保留数据；旧版内容显示时仅取首个元素，位置归零，
宽高逐轴限制到活动框，并按文字框对齐。`RichText` 和旧字段 `Text`
都是 `TextSaveInfo`，内部可能还有一层 `RichText`。优先读取新字段。
文字框的 `TextVerticalAlignment/Offset`、`TextHorizontalAlignment/Offset`
兼容无 `Text` 前缀的旧字段。Right/Bottom 偏移为右/下边距，正值向内移动。
缺省段落水平居中。元素和整页的原始 XML 均保留。
旧 `Source` 已废弃，仅保留于 XML，不作为背景图来源。

## 分类关联与兼容解析

支持 `Config/ClassifyConfig/Classifies/Classify`，以及类型直接表示在
`Config` 节点上的 `Config/Classifies/Classify`。分类包含 `Id`、`Name`、
`Items/Item`，每个 Item 包含 `Id`、`Name`。官方创建逻辑将容器元素 ID
写入分类 Id、素材元素 ID 写入 Item Id。

旧版 `Config` 纯文本按 JSON 读取 `Classifies[].Id/Name/Items[].Id/Name`。
模式为 `Classical` 或 `0` 时允许当前分类玩法；`Fighting`/`1` 暂不支持。
缺失或重复 ID、找不到角色匹配的页面元素、组合内活动成员、损坏配置、
未知玩法均降级静态展示，并记录 `unknown-parameter` 兼容性诊断。

## 当前运行行为

- 首版仅运行 `Key=Classify` 的经典分类；其他玩法展示保存外观。
- 普通播放即可拖动素材，单次允许一个指针，支持鼠标、笔和触摸 Pointer 事件。
- 官方普通容器未指定热点生成器时使用 `TransformedBounds()`；当前按旋转矩形
  的页面外接矩形作为默认热点。素材中心进入最上层关联容器才判题。
- 正确按配置元素 ID 接受；没有内嵌元素的纯文字素材也可按关联素材的去首尾空白文字接受。
  成功动画结束后隐藏素材并累计进度。错误返回本次拖动起点；容器外松手保留新位置，
  下次拖动以新位置为起点。位置只保存于会话。
- 拖入容器用 150ms 放大到 1.2 倍，离开恢复。成功时容器在 0/100/200/300ms
  依次缩放到 1.2/1.3/0.8/1，素材在 400ms 内缩小到零。失败时容器保持 1.2 倍
  到 500ms，700ms 恢复；纵向位移在 0/100/200/300/400/450/500ms 为
  0/-60/0/-40/0/-20/0 页面像素；素材从 500ms 起用 200ms 返回，曲线为
  `cubic-bezier(0, 0.7, 0.7, 1)`。动画期间禁止重复答题，切模式/离页/失焦会结算
  并清理反馈动画。以上为静态 Storyboard 参数移植，尚未逐帧对照官方窗口。
- 完成后显示完成状态；重新开始恢复全部素材和进度，保留其他元素的会话修改。
- 切换选择、离页、失焦、取消捕获或改变缩放会取消尚未提交的拖动。
- 进度以活动定义对象为 WeakMap 键保存在当前文档会话，翻页卸载再挂载可恢复；
  不修改页面元素、原始 XML 或导出数据，新解析的课件使用新状态。
- 活动表面和控制条避让点击动画/翻页和滑动翻页。播放选择禁用活动成员的变换、
  克隆、置顶、删除，含活动成员的组合也不能选择；普通元素选择行为保留。
- 缩略图递归排除活动内音视频和 Flash，并清除活动定义，始终展示初始外观。

尚未实现官方的完成弹窗、随机重排、
音效、计时计分、双人对抗、多点同时答题、填空文字热点和活动编辑/回写。
当前反馈条是播放器 UI，未还原官方模板控件。宿主批注/播放的真实触摸路由尚待实测。

## 真实课件兼容验证

用户提供的 `测试课堂活动1.enbx` 共四页，第 2 页为经典 `Classify`，包含两个岛屿容器
和十二个螃蟹素材。图片直接保存在 `ActivityItem/Background/ImageBrush/Source`，
值为 `id://资源ID`，通过 `Reference.xml` 关联 PNG；这些图片无需从官方模板生成。
通用画刷解析须独立读取 `Source`，不能把 Stretch、Opacity、矩阵等后续字段的
节点文字拼入资源 ID。此规则也适用于页面背景图。

浏览器加载该课件后，已确认第 2 页全部 14 张活动图片解码成功。成功素材的外层、
内容层及图片计算样式均为 `visibility: hidden`；内容层必须继承外层可见性，
不得显式使用 `visible` 覆盖答题隐藏状态。重新开始清除隐藏状态。
第 4 页为 `SuperClassify`，当前仍只展示保存外观，不支持该玩法交互。
本次浏览器截图受窗口可见性限制未取得，以上为真实资源加载与 DOM 样式验证，
不表示已经完成与官方画面的逐像素对照。
