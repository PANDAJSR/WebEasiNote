第 5 页的颜色产生独立指纹。第 15 页最初因为 `ShowRotateOrigin=False` 被保守排除，确认该值表示关闭后允许进入缓存；与普通页逐元素对比，1235 个图形的 `Path`、`ShapePaths` 均相同，差异在原生几何扩展。当前渲染器不使用该扩展，可共享当前绘制结果；未来支持扩展时必须将新几何结果加入指纹。

第 18 页在 1280 × 720 下，Worker 绘制代码用 Skia Canvas 适配器执行约 43 ms；与相同 SVG 绘制计划经 resvg 得到的结果比较，白底合成后的平均 RGB 通道差为 0.146/255，超过 16 的合成通道占比约 0.0017%。原始 RGBA 不适合作为唯一判据：透明边缘 RGB 与预乘 alpha 格式会造成额外差异。该结果验证现有 SVG 与缓存几何的一致性，不验证官方 EasiNote 的视觉保真度。
