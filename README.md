# 希沃白板课件查看器（WebEN）

一个基于 React + TypeScript + Vite 的 第三方 ENBX 课件查看器，用于在浏览器中解析和查看希沃白板课件内容。

## 环境要求

- Node.js 18+
- pnpm 8+

## 快速开始

```bash
pnpm install
```

## 开发运行

启动本地开发服务器（默认端口 `5173`）：

```bash
pnpm dev
```

启动后在浏览器访问终端输出中的本地地址（通常是 `http://localhost:5173`）。

## 生产构建

```bash
pnpm build
```

## 本地预览构建结果

```bash
pnpm preview
```

## 技术栈

- React 18
- TypeScript 5（严格模式）
- Vite 5

## 项目说明

- 本项目主要用于 ENBX 文件内容解析与可视化展示

## 开发提示
